## 1. The Core Method
This laboratory implements the four-stage open-source methodology from the *Overt Psyops* framework:
1. **Identification:** Isolate measurable anomalies between verified truth (**ἀλήθεια**) and platform reach distribution.
2. **Documentation:** Record exact timestamps, follower counts, view counts, and local `SHA-256` cryptographic hashes of screenshot evidence.
3. **Circumvention:** Host primary records outside algorithmic feeds using open repositories, static web tools, and independent timestamping (**OpenTimestamps** / RFC 3161).
4. **Replication:** Keep all code, scoring rules, and ledgers completely forkable under **AGPL-3.0** so any independent researcher can mirror and verify the data.

## 2. The Four-Quadrant Classification
Every logged post is evaluated on two pre-committed axes defined in [`METHOD.md`](./METHOD.md): **Verification** (passing all five **λόγος** criteria) and **Relative Reach** (compared against the account's median 20-post baseline):

* **Quadrant 1:** Unverified content + Normal reach (≥ 50% of baseline)
* **Quadrant 2:** Unverified content + Low reach (< 50% of baseline)
* **Quadrant 3:** Verified **ἀλήθεια** (Truth) + Normal reach (≥ 50% of baseline)
* **Quadrant 4 (Documented Suppression Signature):** Verified **ἀλήθεια** (Truth) + Collapsed reach (< 50% of baseline)
